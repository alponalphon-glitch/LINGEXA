# Iteration 27 — Seasonal Rewards

- Replaced the bottom navigation League/Rating destination with Rewards.
- Added a seasonal rewards page for each of the six learning modules.
- Seasonal cycle rotates through Spring, Summer, Autumn and Winter.
- Each module has five reward milestones at 10, 25, 50, 75 and 100 completed levels.
- Rewards grant Gems and XP and can be claimed once per module, milestone and season.
- Reward availability is based on the module's saved unlocked-level progress.
- Existing League feature remains reachable from the Practice Center; it is no longer a bottom navigation destination.
- Added a source backup before the change.

Android build and on-device testing have not yet been performed.
