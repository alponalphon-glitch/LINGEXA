# Module 4 game redesign

Module 4 now uses the same level-game flow as the earlier redesigned modules:
- 100 levels with 10 questions per level.
- Blue owl mascot appears on every question and gives Russian feedback.
- All Module 4 screen labels, prompts, word choices, and learning examples are English.
- Five shared hearts; a wrong answer consumes one heart. Hearts regenerate at the existing 30-minute cadence.
- Correct answers award 7 XP and 1 Gem; finishing a level awards 20 XP and 4 Gems.
- Progress is persisted with the existing `m4_step_*` and `module4_unlocked` preferences.
- Completing all 100 levels unlocks Module 5.

The existing Module 4 word bank and sample-sentence generator were retained. This change redesigns the interaction and feedback flow; it does not claim that the existing word bank has been linguistically curated.
