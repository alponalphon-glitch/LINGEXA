# Module 6 — Advanced Word Studio

- 100 game levels, 10 advanced vocabulary questions per level.
- Blue owl mascot appears in every question and gives Russian feedback for correct and incorrect answers.
- All app interface labels, prompts, vocabulary and examples are in English; no Tajik UI strings are used in this module.
- Five shared hearts; an incorrect answer removes one heart. Hearts regenerate using the app's existing 30-minute heart timer, including while the app is closed.
- Correct answer: +7 XP and +1 Gem. Completing a level: +20 XP and +4 Gems.
- Progress and unlocked levels are saved locally.
- English dictionary definitions are loaded from dictionaryapi.dev when online; no invented definition is shown when lookup fails.
- Text-to-speech is available for each word and example sentence.
