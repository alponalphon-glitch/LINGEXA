# Module 2 — Everyday Adventures redesign

- Preserves the existing 100-level map and per-level 10-question progress (`m2_step_<level>`).
- Adds a five-heart energy gate using the app's existing 30-minute heart regeneration timer.
- A wrong answer consumes one heart and shows Russian mascot feedback; when hearts reach zero, the learner sees the energy screen and can return after regeneration.
- Correct answers award XP and Gems, advance the question, and complete/unlock levels as before.
- Module 2 learning UI, prompts, choices, buttons, progress labels, and navigation remain English.
- The blue bird mascot's conversational guidance and answer feedback are Russian. No Tajik text is added to Module 2.
- Sentence audio remains available through Android Text-to-Speech.
